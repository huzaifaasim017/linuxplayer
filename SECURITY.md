# Security policy

Supported releases are the latest published version and the current `main` branch. Older packages may receive a fix when practical but are not guaranteed updates.

Please do not disclose a potential security issue in a public issue. Use GitHub's [private vulnerability report](https://github.com/teamkrope/linuxplayer/security/advisories/new) with a short description, reproduction steps, and affected version. If GitHub reporting is unavailable, contact [contact@teamkrope.com](mailto:contact@teamkrope.com). Please allow time to investigate before public disclosure. Never send private media or credentials as sample files.
