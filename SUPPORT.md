# Support

For installation and usage, start with the [README](README.md) and [build notes](docs/BUILDING.md). Search [existing issues](https://github.com/huzaifaasim017/linuxplayer/issues) before filing a bug. Include your LinuxPlayer version, distribution, desktop session (Wayland or X11), exact steps, and relevant logs. Do not upload private or copyrighted videos.

For feature ideas, use the feature request issue form. For security concerns, follow [SECURITY.md](SECURITY.md).
