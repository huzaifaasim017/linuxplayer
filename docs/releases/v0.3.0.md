LinuxPlayer 0.3.0 adds a compact mini-player and refreshes the playback interface.

### What changed

- The hidden-controls reveal action is now a single eye icon.
- The header and playback dock are slimmer, with softer translucent surfaces and clearer SVG controls.
- The picture-in-picture button or **I** turns the current window into a compact player without interrupting playback. Drag the top edge to move it, resize from the bottom-right corner, and press **I** or **Escape** to restore it.
- **C** toggles subtitles, and number keys **0–9** jump through the video.
- The empty state and interface screenshots have been updated.

### Install and compatibility

Use the command in the [README](https://github.com/huzaifaasim017/linuxplayer#install). The installer checks which package fits the system's dependencies and verifies its checksum before installation. Packages are built and install-tested on Ubuntu 24.04 LTS and 26.04 LTS (amd64). Other Debian-based systems may work when compatible libraries are available.

The mini-player asks the window manager to keep it on top. Some Wayland compositors may ignore this hint; playback, resize, and restore remain available.
