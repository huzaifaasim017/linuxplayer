## What changed

- The desktop app now uses the final LinuxPlayer bird logo and the website's navy and teal color palette.
- One `.deb` per CPU architecture replaces the Ubuntu-version-specific downloads. Packages are built on Ubuntu 24.04 and install-tested on Ubuntu 24.04 and 26.04.
- ARM64 release packages and automatic architecture selection in the installer are available.
- The README and website present one primary **Download for Linux** action.
- Playback starts with the controls fading away immediately. Clicks, skips, scrubbing, volume, and fullscreen have brief on-video feedback.
- Ubuntu/GNOME system accent is an optional player setting; brand teal remains the default.
- **Make default video player** is hidden after all supported video associations point to LinuxPlayer and returns if another app becomes the default.
- The shortcuts popup opens above the bottom controls and scrolls in small windows.

## Install

Use the [Download for Linux button](https://github.com/teamkrope/linuxplayer#download) or the terminal installer in the README. Existing installations can install the latest package over an earlier version.
