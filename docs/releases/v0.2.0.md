LinuxPlayer 0.2.0 brings a cleaner viewing experience and a simpler installation path.

### Install

Ubuntu **24.04 LTS** and **26.04 LTS** on amd64 are supported. The [README](https://github.com/teamkrope/linuxplayer#install) has one command that detects your Ubuntu version, verifies the download, and installs the matching package. You can also download the corresponding `.deb` below and install it with `sudo apt install ./filename.deb`.

### Changes

- Minimal start screen, compact translucent controls, and sharper icons.
- Hide or show all controls with the eye button or **H**.
- Replay a finished video with Play.
- A subtle loading indicator for slow file opens or buffering.
- Looping, fit/fill, playback speed, audio and subtitle tracks, frame capture, and resume playback.

### Scope

This is an early desktop release for local video files. Wayland playback was checked on Ubuntu 26.04. Automated build, startup, and package install checks run on Ubuntu 24.04 and 26.04. X11 and other Ubuntu/Debian versions have not been checked for this release. A media library and online playback are outside the current scope.

Source, build instructions, and license information are in the [repository](https://github.com/teamkrope/linuxplayer).
