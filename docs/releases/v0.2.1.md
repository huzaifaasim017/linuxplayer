LinuxPlayer 0.2.1 improves installation across Debian-based Linux systems.

The [README](https://github.com/teamkrope/linuxplayer#install) has the install command. The installer checks each available package against your system's dependencies and uses the compatible one. It verifies the download's SHA-256 checksum before installing.

Release packages are built and install-tested on Ubuntu 24.04 LTS and 26.04 LTS (amd64). Other Ubuntu and Debian-based versions may also work when compatible libraries are available. If neither package fits, the installer stops and points to the [source build guide](https://github.com/teamkrope/linuxplayer/blob/main/docs/BUILDING.md).

The player includes translucent controls, a hide/show button, replay after a video ends, a loading indicator, seeking, speed, audio and subtitle tracks, frame capture, and resume playback.
