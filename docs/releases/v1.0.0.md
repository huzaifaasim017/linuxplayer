# LinuxPlayer 1.0.0

LinuxPlayer 1.0.0 is the first stable release of the redesigned local video player. It brings the desktop app, installer, documentation, and project website into one open-source repository under TeamKrope.

## Highlights

- A calm video-first interface with smooth, immediate control hiding. The old eye button is replaced by a lock control. During ordinary playback, no reveal button remains on screen; in lock mode, moving the pointer briefly offers an unlock button. **H** locks or unlocks controls.
- The bird artwork now sits on a white rounded-square launcher icon so its dark details stay visible in both dark and light desktop themes. The app and website use the same asset.
- Play/pause, seeking, skipping, volume, and fullscreen have brief visual feedback. Videos replay from the start when Play is pressed after they end, and slow loading shows a delayed spinner.
- A compact mini-player, resume prompt, external subtitles, audio and subtitle tracks, looping, playback speed, frame capture, and a keyboard shortcut guide.
- Canvas preview with common aspect ratios, a custom ratio, and Fit/Fill. This changes the playback canvas only; it does not edit or export video.
- A user-triggered option to make LinuxPlayer the default video player. It hides when LinuxPlayer already owns the supported video file associations.
- A simplified website and installer with a primary amd64 download, optional ARM64 package, checksums, and architecture detection in the terminal installer.

## Install and compatibility

Use the [Download](https://github.com/teamkrope/linuxplayer/releases/latest/download/linuxplayer_amd64.deb) button for 64-bit x86 computers, or run the installer in the [README](../../README.md) for automatic amd64/ARM64 selection. Packages are built on Ubuntu 24.04 and install-tested on Ubuntu 26.04. Other Debian-based desktops can work when their package libraries satisfy the `.deb` dependencies. Wayland and X11 are supported by Qt; always-on-top mini-player behavior depends on the window manager or compositor.

For source builds, see [Building](../BUILDING.md). For help, use [Support](../../SUPPORT.md) or contact [contact@teamkrope.com](mailto:contact@teamkrope.com).
