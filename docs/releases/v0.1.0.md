First public preview of LinuxPlayer, a modern video player for local files.

### Install

This package supports **Ubuntu 26.04 (amd64)**. Download `linuxplayer_0.1.0_ubuntu26.04_amd64.deb` below, then run:

```bash
sudo apt install ./linuxplayer_0.1.0_ubuntu26.04_amd64.deb
```

Open **LinuxPlayer** from the app menu or run `linuxplayer`. `apt` installs the runtime dependencies automatically.

### Included

Local video playback, seeking, speed and volume controls, fullscreen, audio and subtitle track selection, external subtitles, and resume playback.

### Preview limits

Wayland playback was checked on Ubuntu 26.04. X11 and other Ubuntu or Debian releases have not been verified for this package. A media library is outside this MVP. A SHA-256 checksum is attached alongside the package.

Source and build instructions are available in the repository's [README](https://github.com/teamkrope/linuxplayer#readme).
