## What changed

- Includes the redesigned player, responsive playback feedback, desktop accent option, default-player handling, and architecture-specific packages from the 0.5 series.
- Release builds now use the standard Ubuntu mirrors to avoid stalls on GitHub's Azure package mirror.

## Install

Download the amd64 or ARM64 package from this release, or use the installer in the README. Existing installations can install this package over an earlier version.
