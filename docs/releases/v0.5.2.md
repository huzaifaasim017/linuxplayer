## What's new

- LinuxPlayer is now maintained in the TeamKrope GitHub organization, with project contact at contact@teamkrope.com.
- The project website is included in the repository so contributors can improve it alongside the app.
- The installer can replace an incomplete older installation after a distribution upgrade changes Qt package names.
- Playback now clears every control, including the old reveal icon. A lock button offers distraction-free mode; move the pointer briefly to reveal unlock, or press H.
- Includes the redesigned player, instant control hiding, playback feedback, system accent option, and amd64/ARM64 downloads from the 0.5 series.

## Install

Use the [Download for Linux button](https://github.com/teamkrope/linuxplayer#download) or follow the simple installer in the README. Existing installations can install this release over an earlier version.
