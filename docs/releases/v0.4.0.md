## What changed

- Preview playback in common social canvas ratios or a custom width:height ratio. The original video is unchanged.
- Set LinuxPlayer as the default application for supported video types from **More options**, with explicit user action and association verification.
- Open the full keyboard shortcut guide with **F1**.
- Updated contributor, interface, support, and security guidance.

## Install

Follow the two-command installer in the [README](https://github.com/teamkrope/linuxplayer#install). Existing installations can run it again to update.
